# BodyPix model asset

This directory contains the TensorFlow.js BodyPix MobileNetV1 1.0, output-stride 8, quantized 2-byte model used for click-targeted, single-frame player segmentation.

- Source: `https://storage.googleapis.com/tfjs-models/savedmodel/bodypix/mobilenet/quant2/100/model-stride8.json`
- Upstream project: `@tensorflow-models/body-pix`
- License: Apache-2.0 (TensorFlow.js Models)

The files are served locally by the application. Runtime player images and video frames are not sent to an external inference service.
